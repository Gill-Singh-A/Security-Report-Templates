\subsection{Approach}
% <EDIT> Describe the actual methodology used for this assessment.
\begin{enumerate}
  \item \textbf{Static surface map.} \fillme{Deterministic inventories of every sink class (SQL
        execution sites, XSS sinks, upload/file sinks, command/dynamic execution, secrets, exposed
        source/backup files) to quantify prevalence and partition the work.}
  \item \textbf{Systematic review.} \fillme{Describe how the codebase was divided and reviewed --
        e.g. per-module review, or a multi-pass finder + adversarial-verifier process.}
  \item \textbf{Synthesis.} Findings were de-duplicated by pattern, ranked by severity and
        exploitability, and compiled into this report.
\end{enumerate}
