\subsection{Approach}
\begin{enumerate}
  \item \textbf{Document review.} Policies, standards, and procedures reviewed against each
        control requirement.
  \item \textbf{Configuration/technical review.} Sampled systems checked for technical control
        implementation (e.g. encryption, logging, access control lists).
  \item \textbf{Interviews.} Control owners interviewed to confirm processes are followed in
        practice, not just documented.
  \item \textbf{Gap rating.} Each control rated Compliant / Partial / Non-Compliant / Not
        Applicable, with evidence referenced.
\end{enumerate}
