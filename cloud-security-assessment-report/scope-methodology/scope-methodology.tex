\subsection{Approach}
\begin{enumerate}
  \item \textbf{Inventory.} Enumerate all accounts/subscriptions/projects, regions, and resource
        types in scope.
  \item \textbf{Automated baseline scan.} Run the chosen benchmark (via \texttt{Prowler}/\texttt{ScoutSuite}/
        native tooling) to get a first-pass control-by-control result set.
  \item \textbf{Manual verification.} Each automated finding is manually verified against the
        live configuration (false positives from stale benchmarks are common); manual review adds
        checks the benchmark does not cover (e.g. cross-account trust relationships).
  \item \textbf{Risk contextualisation.} Findings are re-prioritised based on actual exposure
        (public reachability, data sensitivity, blast radius) rather than benchmark severity alone.
\end{enumerate}
