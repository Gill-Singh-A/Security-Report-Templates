\subsection{Approach}
\begin{enumerate}
  \item \textbf{Enumeration.} \fillme{e.g. an automated enumeration tool (linPEAS or similar) was
        run from the unprivileged foothold on each host.}
  \item \textbf{Candidate triage.} Every candidate vector the tool surfaced was individually
        assessed for applicability against the host's actual patch level and configuration,
        rather than trusted at face value.
  \item \textbf{Adversarial verification.} \fillme{Describe how candidates were confirmed or
        rejected -- e.g. cross-checked against distro changelogs / backport status before being
        marked Confirmed, Version-in-range-unverified, or Not-applicable.}
  \item \textbf{Selective live exploitation.} \fillme{Describe how many / which hosts had live
        PoC exploitation, vs. analytical mapping only, and why.}
\end{enumerate}

\begin{notebox}
\small\textbf{Verifier note.} \fillme{e.g. "Automated tooling flags many CVEs by version range
alone; most were rejected as patched distribution backports after manual verification. Do not
read a registry match as an exploitable bug without a runtime check."}
\end{notebox}
